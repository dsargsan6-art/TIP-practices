## Запуск

Рабочая папка: `practice-06`. Установка пакетов не требуется.

```bash
npm start       # одновременно API (порт 5505) и сайт (порт 5506)
npm test        # проверки сервера, модулей и интеграции
```

Адреса после `npm start`:

- `http://127.0.0.1:5506/` — приложение;
- `http://127.0.0.1:5506/index.html?dataset=variant` — фильтры варианта 8;
- `http://127.0.0.1:5506/checks.html` — браузерные проверки (работают только при `npm start`).

API ПР5 и ПР6 используют один порт 5505, поэтому одновременно запускать можно только одну из работ.

## Что реализовано

| Файл | Назначение |
|---|---|
| `src/api-client.js` | Клиент из ПР5, расширенный методами POST, PATCH, DELETE и телом запроса (`Content-Type: application/json`). |
| `src/task-api.js` | Доменные методы: `getTasks`, `createTask`, `updateTask`, `setTaskCompleted`, `deleteTask`, `resetDemoData`. |
| `src/form-validation.js` | Проверка названия, приоритета и существования категории. |
| `src/task-view.js` | Карточки задач (безопасный вывод через `textContent`). |
| `src/app-controller.js` | Состояние приложения: загрузка (`loading/ready/empty/error`), отмена устаревших запросов, блокировка кнопок на время изменения, повторная загрузка списка после успешной мутации. |
| `src/dom-app.js`, `src/main.js` | Адаптер DOM и точка входа (из заготовки). |
| `src/variant.js` | Номер варианта 8. |

Изменение задачи происходит только через API: после `PATCH /api/tasks/:id` приложение заново запрашивает список с текущими фильтрами. `localStorage` как источник данных не используется.
