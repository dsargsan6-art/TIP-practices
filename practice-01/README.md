### Задание 1. Среды выполнения
- В Node.js: `typeof document` возвращает `undefined`, так как среда выполнения Node.js не содержит встроенного браузерного DOM.

### Задание 2. Исследование типов
| Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |
|---|---|---|---|---|
| `"8" + 2` | `"82"` | `"82"` | `string` | Бинарный оператор `+` при наличии строки выполняет конкатенацию. Число `2` неявно приводится к строке `"2"`. |
| `"8" - 2` | `6` | `6` | `number` | Оператор вычитания `-` не определен для строк, поэтому строка `"8"` неявно приводится к числу `8`, затем выполняется `8 - 2 = 6`. |
| `Number("8") + 2` | `10` | `10` | `number` | Явное преобразование `Number("8")` возвращает число `8`. Сложение двух чисел: `8 + 2 = 10`. |
| `"12" > "3"` | `false` | `false` | `boolean` | Сравнение двух строк выполняется лексикографически (посимвольно по кодам Unicode). Первый символ `'1'` (код 49) меньше символа `'3'` (код 51), поэтому `"12" > "3"` дает `false`. |
| `12 === "12"` | `false` | `false` | `boolean` | Строгое равенство `===` проверяет как значение, так и тип без неявного приведения типов. Число и строка имеют разные типы (`number` и `string`), поэтому результат `false`. |
| `Number("")` | `0` | `0` | `number` | По стандарту ECMAScript преобразование пустой строки через `Number()` дает `0`. |
| `Number("text")` | `NaN` | `NaN` | `number` | Нечисловая строка не может быть разобрана как валидное число, возвращается специальное значение `NaN` (Not-a-Number), тип которого `number`. |
| `Boolean("false")` | `true` | `true` | `boolean` | Любая непустая строка в логическом контексте является истинной (`truthy`), независимо от ее содержимого. |
| `typeof null` | `"object"` | `"object"` | `string` | Историческая особенность (баг первой реализации JavaScript), сохраненная для обратной совместимости. |
| `typeof NaN` | `"number"` | `"number"` | `string` | `NaN` является специальным числовым значением согласно стандарту IEEE 754, его тип — `number`. Сам результат оператора `typeof` всегда возвращает строку. |
