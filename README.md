## Запуск

Рабочая папка: `practice-04`. Установка пакетов не требуется, нужны только Node.js и браузер.

```bash
npm test        # проверки сервиса и модулей (Node.js)
npm start       # статический сервер на порту 5504
```

Адреса после `npm start`:

- `http://127.0.0.1:5504/` — общий набор задач;
- `http://127.0.0.1:5504/index.html?dataset=variant` — вариант 8;
- `http://127.0.0.1:5504/examples/forms-storage.html` — эксперименты с формой и хранилищем;
- `http://127.0.0.1:5504/checks.html` — браузерные проверки.

Если `npm.ps1` заблокирован в PowerShell, используйте `npm.cmd start` или `node tools/serve.mjs`.

## Что реализовано

| Файл | Назначение |
|---|---|
| `src/data.js` | Общий набор `demoTasks` и задачи варианта 8 (перенесены из ПР3). |
| `src/task-service.js` | Чистые функции ПР2–ПР3 и новая `updateTask`. |
| `src/task-selectors.js` | `getVisibleTasks` для фильтров all / pending / completed. |
| `src/task-view.js` | Карточка задачи с кнопками «Выполнена», «Изменить», «Удалить», сводка, пустые состояния. |
| `src/form-validation.js` | `validateTaskDraft` — чистая прикладная проверка id, названия и приоритета. |
| `src/task-storage.js` | `loadTasks`, `saveTasks`, `removeSavedTasks`, `isValidTaskList`: JSON `{ version: 1, tasks }` в `localStorage`. |
| `src/main.js` | Форма (создание и редактирование), фильтры, сохранение и сброс данных. |

Ключ хранилища общего набора: `tip-js-practice-04:demo`.

## Организация кода

- Функции хранения получают объект `storage` аргументом, поэтому их можно проверять без настоящего `localStorage`.
- Данные из JSON проверяются (`isValidTaskList`) до использования: повреждённая запись заменяется исходным набором, приложение не падает.
- `validateTaskDraft` не обращается к DOM и не меняет входные данные; показ ошибок выполняется в `main.js`.
- Выбор фильтра в `localStorage` не записывается, сохраняются только задачи.
