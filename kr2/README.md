# Контрольная работа № 2

Проверки используют готовые решения ПР4–ПР6 из этого репозитория. Перед запуском нужен установленный Node.js.

| Задание | Что проверяется | Как запустить |
|---|---|---|
| 1 | Проверка названия в `validateTaskDraft` (ПР4) | `node task1-validate-title.mjs` в папке `kr2` |
| 2 | Сохранение после перезагрузки (ПР4) | `npm start` в `practice-04`, затем браузер: `http://127.0.0.1:5504/` |
| 3 | Получение задач с сервера (ПР5) | `npm start` в `practice-05`, затем `node task3-get-tasks.mjs` в папке `kr2` |
| 4 | Обработка HTTP-ошибки (ПР5) | при работающем API: `node task4-http-error.mjs` в папке `kr2` |
| 5 | Изменение задачи через API (ПР6) | остановить API ПР5, `npm start` в `practice-06`, затем браузер: `http://127.0.0.1:5506/` |

## Ожидаемые результаты

1. `title = " Изучить localStorage "` → `ok: true`, `value.title` без краевых пробелов; `title = " "` → `ok: false` и сообщение в `errors.title`.
2. После добавления задачи id 20 «Изучить localStorage» (приоритет high) и перезагрузки страницы задача остаётся в списке; ключ `tip-js-practice-04:demo` содержит JSON с `version: 1` и массивом `tasks`.
3. `id задач: [ 4, 13, 34 ]`, `meta.total: 3`.
4. `kind: http`, `status: 404`, необработанного исключения нет.
5. В Network: `PATCH /api/tasks/4` со статусом 200, затем `GET /api/tasks?completed=false` со статусом 200; задача 4 исчезает из списка.
